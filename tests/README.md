# Автотесты (Selenium)

## Описание
В данном разделе представлены автотесты для интернет-магазина Beeline:
https://moskva.beeline.ru/shop/
Автотесты реализованы на Python с использованием Selenium WebDriver.

---

## Используемые технологии
* Python
* Selenium WebDriver
* ChromeDriver

## Структура автотестов
```
tests/
│
├── auth_ui        # Авторизация (UI)
├── basket         # Корзина
├── catalog        # Каталог товаров
├── filters        # Фильтры
├── main_page      # Главная страница
├── product_card   # Карточка товара
├── search         # Поиск
```

---

## Покрытые сценарии

### Авторизация (auth_ui)
* открытие окна входа
* переход в авторизацию на сайте
* переключение способов входа (СМС, логин, Mobile ID)

### Главная страница (main_page)
* отображение товаров
* работа header
* переход в карточку товара

### Поиск (search)
* ввод поискового запроса
* частичный поиск
* открытие товара из поиска
* отображение результатов

### Каталог (catalog)
* переход по категориям
* навигация
* пагинация
* smoke-проверки

### Фильтры (filters)
* работа чекбоксов
* сортировка
* фильтр по цене

### Корзина (basket)
* добавление товара
* изменение количества
* удаление товара
* добавление из разных страниц

### Карточка товара (product_card)
* открытие карточки товара
* базовые проверки UI

---


## Особенности

* Тесты написаны в упрощённом формате без использования pytest
* Используется линейный сценарный подход
* Основной фокус — проверка пользовательских сценариев и UI
