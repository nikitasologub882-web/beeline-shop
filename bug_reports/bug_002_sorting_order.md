# BUG-002: Нарушение порядка сортировки товаров по цене

## Описание
Сортировка "по цене от дешевых" и "по цене от дорогих" работает некорректно — порядок товаров нарушен.

## Окружение
- Платформа: Web
- Браузер: Chrome
- URL: https://moskva.beeline.ru/shop/catalog/telefony/

## Предусловия
Открыта страница каталога товаров.

## Шаги воспроизведения
1. Перейти в каталог смартфонов.
2. Выбрать сортировку:
   - "по цене от дешевых"
3. Проверить порядок цен товаров.
4. Повторить для:
   - "по цене от дорогих"

## Фактический результат
- Товары отображаются в **несортированном порядке**
- Значения цены идут с нарушением последовательности

## Ожидаемый результат
- При выборе "по цене от дешевых":
  цены должны возрастать (min → max)
- При выборе "по цене от дорогих":
  цены должны убывать (max → min)

## Severity
Medium

## Priority
High

## Влияние
- Пользователь не может корректно подобрать товар по цене
- Ухудшается UX
- Потеря конверсии
