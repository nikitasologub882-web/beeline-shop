# BUG-001: Несоответствие цвета товара между UI и API

## Описание
Цвет товара, отображаемый в UI, не совпадает с данными, полученными из API.

## Окружение
- Платформа: Mobile
- Браузер: Chrome
- Инструменты: Proxyman
- URL: https://moskva.beeline.ru/shop/

## Предусловия
Открыта карточка товара.

## Шаги воспроизведения
1. Открыть карточку товара (например Xiaomi Redmi A3x).
2. Обратить внимание на цвет товара в UI.
3. Открыть Proxyman.
4. Найти запрос к API (basket / product).
5. Проверить поле `productName` или данные о цвете.

## Фактический результат
- В UI цвет товара: **Зелёный**
- В API цвет товара: **Чёрный**

## Ожидаемый результат
Цвет товара в UI должен полностью соответствовать данным из API.

## Severity
High

## Priority
High

## Влияние
- Пользователь получает неверную информацию о товаре
- Возможны ошибки при заказе
- Потеря доверия к сервису
