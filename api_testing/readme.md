# 📱 Beeline Shop API Testing

## 📂 Структура тестов

### 🔍 01. Health & Availability
- `GET` Health Check стороннего сервиса
- `GET` Главная страница HTML
- `GET` Каталог "Смартфоны"
- `GET` Каталог тарифов
- `GET` Поиск по сайту (автодополнение)

### 🎯 02. Content & Blocks
- `GET` API акций и рекомендаций (Flocktory)
- `GET` Autocomplete
- `GET` blocks2024
- `GET` Lottie анимация для десктопа
- `GET` Топ тарифы (страница)

### 📦 03. Product Catalog
- `POST` Категории
- `GET` Рекомендованные товары
- `GET` Карточка товара HTML
- `POST` Фильтрация товаров
- `POST` Сортировка (от дешевых)

### 🛒 04. Cart

#### Добавление и просмотр
- `POST` Добавить товар в корзину
- `GET` Получить содержимое корзины
- `GET` Определение локации для доставки
- `GET` Возврат список офисов Билайн

#### Изменение корзины
- `PUT` Изменить количество товара
- `PUT` Удалить один товар
- `DEL` Удалить товар из корзины
- `PUT` Обновление данных клиента в корзине

#### Оформление заказа
- `POST` Перерасчет корзины
- `POST` Создание заказа из корзины
- `GET` Получить информацию о заказе
- `PUT` Сохранение выбранного офиса
- `GET` Получение способов оплаты
- `PUT` Установление способа оплаты
- `GET` Получение полных данных заказа

### 👤 05. User

#### Авторизация
- `POST` Процесс авторизации
- `POST` Отправка учетных данных
- `POST` Получение токена/сессии
- `GET` Успешная авторизация

#### Профиль
- `GET` Загрузка контента для бокового меню
- `GET` balanceopurp_content

## ✅ Типы проверок
- **Status codes:** 200, 201, 400, 401, 404
- **JSON Schema** валидация
- **Business logic** тесты
