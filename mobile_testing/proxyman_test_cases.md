## Установка сертификата Proxyman на Android устройство

**Предусловия**

* Proxyman установлен на ПК
* ПК и телефон подключены к одной Wi-Fi сети
* Proxyman запущен

**Шаги**

1. Открыть Proxyman на ПК
2. Перейти в меню **Certificate → Install Certificate on Android**
3. Следовать инструкции установки сертификата
4. На телефоне открыть **Настройки Wi-Fi**
5. Выбрать текущую сеть
6. Открыть **Дополнительные настройки → Proxy → Manual**
7. Указать

   * IP ПК
   * Порт `9090`
8. Открыть браузер на телефоне
9. Перейти на адрес

```
http://proxy.man/ssl
```

10. Скачать сертификат
11. Установить сертификат через

```
Настройки → Биометрия и безопасность → Шифрование и учетные данные → Установить сертификат → CA сертификат
```

**Ожидаемый результат**

* Сертификат успешно установлен на устройстве
* HTTPS-трафик можно расшифровывать в Proxyman

**Фактический результат**

Заполняется после выполнения теста

**Приоритет**

Высокий

**Предусловия**

* Прокси настроен
* Сертификат установлен
* Proxyman запущен

**Шаги**

1. Убедиться что в Proxyman отображается

```

```

2. Открыть приложение **Билайн** на телефоне

* В Proxyman появляются HTTP/HTTPS запросы приложения
* В списке отображаются

  * Status
  * Time

## Анализ структуры HTTP запроса

**Предусловия**

* В Proxyman есть перехваченные запросы

**Шаги**

1. Найти запрос

   * Method: **GET**
   * Status: **200**
2. Выбрать данный запрос
3. Открыть вкладку

```
Request Headers
```

4. Проверить наличие следующих заголовков

* `User-Agent`
* `Accept-Language`

**Ожидаемый результат**

* В заголовках присутствует информация об устройстве
* Указан язык приложения

Пример:

```
User-Agent: Android
Accept-Language: ru-RU
```

**Фактический результат**

Заполняется после выполнения теста

**Приоритет**

Средний

## Модификация HTTP запроса через Breakpoint

**Предусловия**

* Найден запрос поиска товаров

**Шаги**

1. Кликнуть правой кнопкой по запросу
2. Выбрать

```
Tools → Breakpoint → Request
```

3. Выполнить поиск товара в приложении
4. В окне Breakpoint Editor изменить параметр

```
query=телефон
```

на

```
query=ноутбук
```

5. Нажать **Execute**

**Ожидаемый результат**

* Запрос отправляется с измененным параметром
* Сервер возвращает результаты поиска по новому значению

**Фактический результат**

Заполняется после выполнения теста

**Приоритет**

Высокий

## Подмена ответа через Map Local

**Предусловия**

* Найден запрос списка товаров

**Шаги**

1. Нажать правой кнопкой на запрос
2. Выбрать

```
Save Response
```

3. Сохранить JSON файл
4. Открыть файл и удалить данные из массива товаров
5. В Proxyman выбрать

```
Tools → Map Local → Add Rule
```

6. Указать путь к измененному JSON
7. Обновить экран в приложении

**Ожидаемый результат**

* Приложение получает измененный JSON
* Отображается состояние **нет товаров**

**Фактический результат**

Заполняется после выполнения теста

**Приоритет**

Средний

## Сохранение и загрузка сессии трафика

**Предусловия**

* В Proxyman присутствует трафик

**Шаги**

1. Открыть меню

```
File → Save Session
```

2. Сохранить файл
3. Закрыть Proxyman
4. Открыть Proxyman снова
5. Выбрать

```
File → Open Session
```

6. Открыть сохраненный файл

**Ожидаемый результат**

* Все перехваченные запросы загружаются в Proxyman
