# Mobile Testing Checklist

## 1. Установка и запуск

- [ ] Приложение устанавливается без ошибок
- [ ] Приложение запускается корректно
- [ ] Первый запуск выполняется без зависаний
- [ ] Splash screen отображается корректно
- [ ] Приложение не падает при первом запуске

---

## 2. Авторизация и регистрация

- [ ] Экран авторизации открывается корректно
- [ ] Поле ввода номера телефона работает корректно
- [ ] Поле ввода пароля принимает корректные данные
- [ ] Кнопка входа активна только при валидных данных
- [ ] Отображается ошибка при неверных данных
- [ ] Успешная авторизация выполняется корректно
- [ ] Пользователь остаётся авторизованным после перезапуска
- [ ] Регистрация нового пользователя проходит корректно

---

## 3. Навигация

- [ ] Главное меню открывается корректно
- [ ] Все разделы меню доступны
- [ ] Переход между разделами выполняется корректно
- [ ] Кнопка "Назад" работает корректно
- [ ] Навигация не вызывает зависаний
- [ ] Нижнее меню не перекрывает контент

---

## 4. Каталог товаров

- [ ] Каталог товаров загружается корректно
- [ ] Список товаров отображается без ошибок
- [ ] Изображения товаров загружаются
- [ ] Цена товара отображается корректно
- [ ] Название товара отображается полностью

---

## 5. Поиск товаров

- [ ] Поле поиска доступно пользователю
- [ ] Поиск возвращает релевантные результаты
- [ ] Поиск работает с частичным вводом
- [ ] Поиск работает при вводе полного названия
- [ ] Отображается сообщение при отсутствии результатов

---

## 6. Карточка товара

- [ ] Карточка товара открывается корректно
- [ ] Изображение товара отображается
- [ ] Цена отображается корректно
- [ ] Характеристики товара загружаются
- [ ] Кнопка добавления в корзину работает

---

## 7. Корзина

- [ ] Товар добавляется в корзину
- [ ] Количество товара можно увеличить
- [ ] Количество товара можно уменьшить
- [ ] Товар можно удалить из корзины
- [ ] Итоговая стоимость пересчитывается корректно

---

## 8. Сеть

- [ ] Приложение корректно реагирует на отключение интернета
- [ ] Отображается сообщение об отсутствии сети
- [ ] После восстановления сети данные обновляются
- [ ] Загрузка страниц не зависает при медленной сети
- [ ] Ошибки сети отображаются корректно

---

## 9. UI / адаптивность

- [ ] Интерфейс корректно отображается на мобильном экране
- [ ] Текст не обрезается
- [ ] Кнопки доступны для нажатия
- [ ] Элементы интерфейса не накладываются друг на друга
- [ ] Контент не выходит за границы экрана

---

## 10. Поворот экрана

- [ ] Интерфейс корректно отображается в портретной ориентации
- [ ] Интерфейс корректно отображается в ландшафтной ориентации
- [ ] Данные не теряются при повороте экрана
- [ ] Элементы интерфейса не ломаются при повороте
- [ ] Текущий экран сохраняется после поворота
