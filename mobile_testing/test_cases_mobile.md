# Mobile Test Cases

## TC-MOB-001 Авторизация пользователя

Предусловия: пользователь зарегистрирован

Шаги:
1. Открыть приложение
2. Нажать кнопку "Войти"
3. Ввести корректные данные
4. Нажать кнопку входа

Ожидаемый результат:
Пользователь успешно авторизован и попадает на главную страницу.

---

## TC-MOB-002 Поиск товара

Шаги:

1. Открыть приложение
2. Перейти в каталог товаров
3. Ввести название товара в поле поиска

Ожидаемый результат:

Отображаются релевантные результаты поиска.

---

## TC-MOB-003 Добавление товара в корзину

Шаги:

1. Открыть карточку товара
2. Нажать кнопку "Добавить в корзину"

Ожидаемый результат:

Товар успешно добавляется в корзину.
