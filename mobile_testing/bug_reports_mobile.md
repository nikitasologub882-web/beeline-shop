# Mobile Bug Reports

## BUG-MOB-001

Название: кнопка входа перекрывается экранной клавиатурой

Окружение:
Android 14
Android Emulator Pixel 6

Шаги:

1. Открыть экран авторизации
2. Нажать поле ввода пароля

Фактический результат:

Кнопка входа частично перекрыта экранной клавиатурой.

Ожидаемый результат:

Кнопка входа остаётся доступной пользователю.

Severity: Medium
Priority: Medium
