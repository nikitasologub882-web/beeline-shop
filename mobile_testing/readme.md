# Mobile Testing — Beeline Shop

## Объект тестирования

Интернет-магазин **Beeline Shop**

[https://moskva.beeline.ru/shop/](https://moskva.beeline.ru/shop/)

Тестирование проводилось на мобильных устройствах и эмуляторах Android с целью проверки корректности работы пользовательских сценариев интернет-магазина.

---

# Цель мобильного тестирования

Основная цель тестирования — проверить корректность работы ключевых пользовательских сценариев при использовании сервиса на мобильных устройствах.

В рамках тестирования были проверены следующие сценарии:

* регистрация пользователя
* авторизация пользователя
* навигация по разделам магазина
* поиск товаров
* просмотр карточки товара
* добавление товара в корзину
* изменение количества товара
* удаление товара из корзины
* оформление заказа
* обработка ошибок интерфейса

---

# Проверяемые области

В ходе мобильного тестирования были выполнены проверки следующих аспектов:

### Интерфейс и UX

* корректность отображения элементов интерфейса
* адаптивность интерфейса для мобильных экранов
* корректность отображения карточек товаров
* корректность отображения модальных окон

### Пользовательские сценарии

Проверка основных пользовательских сценариев:

* переход по разделам магазина
* поиск товаров
* просмотр карточки товара
* работа корзины
* оформление заказа

### Обработка ошибок

Проверка поведения системы при возникновении ошибок:

* ввод некорректных данных
* пустые результаты поиска
* ошибки сервера
* отсутствие интернет-соединения

### Поведение интерфейса

Дополнительно проверялись:

* поведение приложения при повороте экрана
* работа экранной клавиатуры
* корректность навигации между экранами
* корректность отображения пустых состояний

### Проверка сетевых условий

Были выполнены проверки:

* поведение приложения при нестабильном соединении
* обработка ошибок сервера
* обработка некорректных ответов API

Для проверки сетевых сценариев использовался прокси-инструмент **Proxyman**.

---

# Используемые устройства и окружение

Тестирование выполнялось на следующих устройствах:

### Эмуляторы

* Android Studio Emulator

### Реальные устройства

* Samsung Android device

Дополнительно использовались инструменты:

* Chrome DevTools
* Proxyman (перехват и модификация сетевых запросов)

# Покрытие тестирования

Мобильное тестирование покрывает ключевые пользовательские сценарии интернет-магазина:

* просмотр каталога товаров
* поиск товаров
* просмотр карточки товара
* добавление товаров в корзину
* управление корзиной
* авторизация пользователя

Также были проверены негативные сценарии:

* некорректные данные авторизации

* отсутствие интернет-соединения
* серверные ошибки
