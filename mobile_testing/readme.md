# Mobile Testing

## Объект тестирования
Интернет-магазин Beeline  
https://moskva.beeline.ru/shop/
Тестирование выполнялось на мобильных устройствах и эмуляторах Android.

---

## Цель мобильного тестирования

Проверка корректности работы основных пользовательских сценариев на мобильных устройствах:

- регистрация пользователя
- авторизация пользователя
- навигация по разделам магазина
- поиск товаров
- просмотр карточки товара
- добавление товара в корзину
- изменение количества товара
- удаление товара из корзины
- оформление заказа

---

## Проверяемые области

В рамках мобильного тестирования были выполнены проверки:
- корректность отображения интерфейса
- адаптивность интерфейса
- работа пользовательских сценариев
- обработка ошибок
- поведение приложения при нестабильной сети
- реакция приложения на поворот экрана
- работа экранной клавиатуры
- корректность навигации

---

## Используемые устройства и окружение
Тестирование выполнялось на следующих устройствах:
- Android Studio Emulator
- Android устройство (Samsung)
