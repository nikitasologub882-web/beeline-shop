В рамках pet-проекта выполнена подготовка тестовой документации для интернет-магазина Beeline.

Содержит:
- функциональные чек-листы
- тест-кейсы пользовательских сценариев
- API тест-кейсы
- таблицу принятия решений
- нефункциональные проверки

Покрытые сценарии:
- регистрация пользователя
- авторизация
- каталог товаров
- карточка товара
- корзина
- оформление заказа

Типы тестирования:
- функциональное тестирование
- негативные проверки
- проверки граничных значений
- API тестирование
