# Beeline Shop — QA Pet Project
Пет-проект по комплексному тестированию интернет-магазина Beeline.

Проект включает:
* тестовую документацию
* API тестирование
* мобильное тестирование
* автотесты на Selenium

---

## Объект тестирования
Интернет-магазин Beeline:
https://moskva.beeline.ru/shop/

---

## Цель проекта
* ручное тестирование веб-приложений
* составление тестовой документации
* API тестирование (Postman)
* мобильное тестирование
* написание UI автотестов (Selenium)

---

## Структура проекта
```
api_testing/        # API тестирование (Postman коллекции)
mobile_testing/     # мобильное тестирование
test_documentation/ # чек-листы, тест-кейсы, тестовая документация
tests/              # автотесты (Selenium)
pages/              # вспомогательные элементы (структура под POM)
```

---

## Покрытые сценарии
В рамках проекта протестированы основные пользовательские сценарии:
* регистрация и авторизация
* поиск товаров
* просмотр каталога
* работа с фильтрами и сортировкой
* просмотр карточки товара
* работа с корзиной
* оформление заказа

---

## Автотесты
Автотесты реализованы с использованием:
* Python
* Selenium WebDriver

Покрытые области:
* главная страница
* каталог
* поиск
* фильтры
* корзина
* авторизация (UI)
