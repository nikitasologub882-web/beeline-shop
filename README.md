
Pet-проект по комплексному тестированию интернет-магазина Beeline.
Проект включает тестовую документацию, API коллекции, мобильное тестирование и автотесты.

# Объект тестирования
Интернет-магазин Beeline:
https://moskva.beeline.ru/shop/

Основные протестированные пользовательские сценарии:
- просмотр каталога товаров
- открытие карточки товара
- фильтрация товаров
- сортировка товаров
- работа корзины
- изменение количества товаров
- удаление товара из корзины
- оформление заказа
- регистрация пользователя
- авторизация пользователя

- тест-кейсы пользовательских сценариев

Покрытые сценарии:

- каталог товаров

# API Testing
API тестирование выполнено с использованием **Postman**.

Проверены основные endpoints:
- получение рекомендованных товаров
- получение карточки товара
- фильтрация товаров
- сортировка товаров
- работа корзины
- добавление товара в корзину
- изменение количества товара
- удаление товара
- создание заказа
- авторизация пользователя

В Postman коллекции реализованы автоматические проверки:
- проверка статус-кода ответа
- проверка формата JSON
- проверка структуры ответа
- проверка наличия обязательных полей
- проверка корректного добавления товара в корзину


# Mobile Testing
Проведено базовое тестирование мобильного приложения Beeline.
Тестирование выполнялось на реальном Android устройстве.

Используемые инструменты:
* Android Studio
* Logcat
* Proxyman

Проверенные сценарии:
* запуск приложения
* авторизация пользователя
* обработка ошибок
* сетевые запросы приложения
* поведение при нестабильной сети

Выполнено:
* анализ сетевого трафика приложения
* перехват HTTP запросов
* анализ логов приложения
* проверка обработки сетевых ошибок


# Automation Tests

В проекте реализованы базовые UI автотесты.

Используемый стек:

Автоматизированы следующие сценарии:
